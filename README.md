# Mini Kitaplık (Ödev-2)

Bu proje, React ve Vite kullanılarak geliştirilmiş küçük bir web kitaplığı uygulamasıdır.

## Özellikler
- Başlık ve yazara göre arama yapma
- Kategoriye göre filtreleme (Web, CS, Tasarım)
- Favorilere kitap ekleme ve çıkarma
- `localStorage` ile son arama metni ve favorileri hatırlama
